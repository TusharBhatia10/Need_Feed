# NeedFeed

A platform connecting donors with old age homes in Mumbai. Donors can browse homes, see what supplies are urgently needed, and pledge donations. Home admins can manage their needs board, track incoming pledges, and confirm deliveries.

## Features

**Donor view**
- Dashboard with urgent needs near you
- Browse and search all registered homes
- Pledge donations with drop-off scheduling
- Track active and completed pledges
- Impact stats and monthly donation history

**Admin view**
- Dashboard with live activity feed
- Needs board — add, edit, and prioritise supply requests
- Incoming pledges tracker — mark deliveries as received
- Donation history with monthly chart
- Home profile editor with shareable donor link

## Tech stack

- React 18
- Vite
- Plain CSS with custom design tokens (dark mode)

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:5173 in your browser.

Use the toggle in the top right corner to switch between the Donor and Home Admin views.
