<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → api.qrserver.com | <img> GET request with encodeURIComponent-encoded URL; no auth, response is a PNG |
| Admin JSX edits | All changes operate on mock data; no user input reaches a backend |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | QR URL construction | mitigate | `encodeURIComponent(shareUrl)` prevents XSS via crafted home name input in form.name field |
| T-03-02 | Spoofing | api.qrserver.com <img> | accept | Third-party CDN returning PNG; no script execution possible from img tag; low risk for prototype |
| T-03-03 | Elevation of Privilege | navigator.clipboard API | mitigate | Graceful fallback to `execCommand('copy')` prevents silent failures on non-HTTPS contexts |
| T-03-04 | Information Disclosure | CSV export of HISTORY data | accept | Mock data only; no PII; Blob URL is immediately revoked after download trigger |
| T-03-SC | Tampering | npm installs | accept | No new packages; lockfile unchanged |
</threat_model>
